Respaldo de datos

Todo se guarda en localStorage de este navegador: no viaja a ningún servidor. Exportá el JSON cada tanto para tener respaldo (o para pasarlo a otro dispositivo).

Sincronización con Notion

Lo definís en el servidor (variable FINANZAS_TOKEN). El token de Notion nunca sale del servidor: el navegador sólo manda y recibe movimientos.
Sin configurar.

Carga rápida desde el iPhone (Action Button / Atajos)

El dashboard acepta datos por URL. Creá un Atajo de iOS con la acción “Abrir URL” y esta dirección (podés pedir el monto con “Pedir entrada”):



Al abrirse, el gasto queda cargado solo y aparece el aviso de confirmación. Parámetros: tipo (gasto|ingreso), monto, cat, desc, fecha (opcional).

Presupuesto mensual

Cuánto pensás gastar por mes en cada categoría. Se usa para las barras de avance y las alertas de sobregiro. Dejalo en 0 para no controlar esa categoría.
